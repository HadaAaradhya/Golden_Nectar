# 💰 Golden Nectar – A Fintech App

Golden Nectar is a modern web and mobile-friendly fintech application built using **React** and **Vite**, designed to help users track income and expenses, set financial goals, view insightful analytics, and share financial milestones.

---

## 🚀 Features

- 🔐 **User Authentication** – Register and login using email or OAuth (Google, Facebook)
- 🎯 **Financial Goal Management** – Create, update, and track financial goals
- 💸 **Income & Expense Tracking** – Record transactions with category tags
- 📊 **Financial Analytics** – View trends and reports in visually engaging dashboards
- 📱 **Social Media Sharing** – Share milestones directly on social platforms
- 🔔 **Notifications** – Get timely alerts for goals, budgets, and more

---

## 🧱 Tech Stack

| Technology    | Description                                 |
|---------------|---------------------------------------------|
| React + Vite  | Fast frontend development                   |
| Firebase      | Backend services (Auth, Firestore, Hosting) |
| Tailwind CSS  | Utility-first CSS framework (optional UI)   |
| OAuth 2.0     | Secure user authentication                  |
| Chart.js / Recharts | Financial data visualization         |
